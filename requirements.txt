# Project runtime dependencies (validated on a clean Python 3.13 env, CUDA 11.8).
#
# Two packages are installed in SEPARATE steps (see scripts/install_env.sh or the README) and
# are intentionally NOT listed here:
#   - torch / torchvision : must be the CUDA 11.8 build (installed first, from the cu118 index)
#   - chumpy              : must use --no-build-isolation (its setup.py imports `pip`, which is
#                           absent under pip's isolated builds -> fails on a fresh machine)
# WiLoR-mini is then installed with --no-deps (the packages below ARE its dependencies).
# Model weights (WiLoR + MANO) auto-download on first run.
#
# Python 3.9 and older are not supported: mujoco, huggingface_hub and scikit-image all require
# 3.10+, and numpy 2.x has no 3.9 wheels for these versions.
#
# `pip check` reports two stale bounds declared by WiLoR-mini (torch<=2.5, ultralytics==8.1.34).
# The versions below are newer and were validated end-to-end (detection + 3D pose + sim teleop) on
# this stack; downgrade to torch 2.5.1+cu118 / ultralytics 8.1.34 if you prefer upstream's bounds.
